# ⛏️ Idle Miner

Idle game de minage inspiré de Minecraft, jouable dans le navigateur.

## Lancer le projet

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:5173.

## Travailler à deux

1. `git pull` pour récupérer la dernière version de `main`.
2. `git checkout -b ma-feature` pour créer sa branche.
3. Coder, puis `git add .` et `git commit -m "..."`.
4. `git push -u origin ma-feature`, puis ouvrir une Pull Request sur GitHub.
5. L'autre teste le lien de preview Vercel, relit le code, puis merge.

Les règles du jeu sont décrites dans [docs/idle_miner_v1.md](docs/idle_miner_v1.md).
